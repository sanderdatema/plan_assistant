<objective>
## Goal
Replace all process.exit() calls in CLI commands with a throwable CliError class, fix stdout pollution in launchServer, and add sessionId validation. This makes the entire CLI testable and fixes a bug where AI agents get corrupted JSON output.

## Purpose
28 process.exit() calls spread across 10 files make integration testing impossible. The launchServer "Starting..." message goes to stdout, corrupting JSON output for AI agents. SessionId is never validated, allowing filesystem corruption from malformed IDs.

## Output
- New `src/cli/errors.ts` with CliError class
- All process.exit() removed from commands (only in main entry point)
- launchServer output moved to stderr
- SessionId validation in session-manager.ts
- Tests for CliError pattern and sessionId validation
</objective>

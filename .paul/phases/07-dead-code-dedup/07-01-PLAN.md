- Server-side `requireSession()` helper eliminating 7 duplicated route guards
- `fetchWithTimeout()` utility replacing 4 duplicated AbortController patterns
- `getVersion` using `readJsonFile`
- All 160 existing tests continue to pass

    Add to `src/cli/server-client.ts`:
    ```typescript
    async function fetchWithTimeout(
      url: string,
      options: RequestInit,
      timeoutMs: number,
    ): Promise<Response> {
      const controller = new AbortController();
      const timeout = setTimeout(() => controller.abort(), timeoutMs);
      try {
        const res = await fetch(url, { ...options, signal: controller.signal });
        return res;
      } finally {
        clearTimeout(timeout);
      }
    }
    ```
